# Reporting a problem

- **An app in the catalog behaves maliciously** (exfiltrates data, hides what it does): open an
  issue titled `Report: owner/repo` with what you observed, or contact the maintainer privately
  through GitHub if publishing the details would put users at risk. The entry is put back in
  review or removed.
- **A vulnerability in Community Apps itself** (integration, workflows, catalog tooling): use
  GitHub's *Report a vulnerability* (Security tab) so it can be fixed before disclosure.

The review only covers a repository when it enters the catalog; see the README section
"What the review is, and what it is not".
